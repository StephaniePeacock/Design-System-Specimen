Foundation and reset

Reset rules that were applied:

*, *::before, *::after { box-sizing: border-box; }
This makes calculating the entire box size easier, as padding and border are included.
*, *::before, *::after { padding:0; }
Resetting the padding globally allows me to ensure that padding is consistent across the entire design.
body, h1, h2, p, ul, figure { margin: 0; }
Removes margins from the above items, allowing for more precise spacing.
button { font: inherit; border: none }
Sets button font to match body font, and removes the button border for a cleaner look.
Omitted: border: 0
I would rather override borders as I come across them, rather than potentially remove one that should be there for accessibility purposes.
Omitted: font: inherit
I wanted to avoid having to restyle every single text item, which is what this command would require. It is more efficient to adjust styling as needed.

This is a paragraph sample. Paragraphs are made up of a series of sentences. The sentences in a paragraph are usually on a related topic, and all bring a singular point into focus. Each sentence is made up of words, spaces and punctuation symbols. These words and symbols are called characters. The Latin alphabet, which is the standard for the English language you are reading, is made up of 26 letter characters. It also makes use of 10 digit characters (0123456789), and a plethora of punctuation marks, such as commas ( , ) periods ( . ) colons ( : ) semi-colons ( ; ) question marks ( ? ) exclamation points ( ! ) and many more.
